# Rules for Creation of Implementation Plan
These rules should be followed by the Architect mode when generating an implementation plan from user story. Carefully analyze the requirements from the user story (or equivalent request) and follow the instructions laid out below.


## Implementation Plan Structure
Follow `docs/requirement-templates/implementation-plan-artifact.md` for the structure of the implementation plan 

## Manual Tasks First 
    - Identify tasks that require human inputs from the requirement. 
    - Generate placeholder files for humans to provide their inputs to. For e.g. Generate .env.local with an API_KEY parameter with a value as <PLACEHOLDER_FOR_HUMAN_INPUT>  
    - Generate Parent tasks and sub-tasks that require human inputs. Tag these with [MANUAL] prefix.
