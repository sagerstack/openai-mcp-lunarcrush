# Solution Architect Rules

## Planning Requirements

### Implementation Plan Structure
- Focus on implementation tasks, not explicit test writing
- Design plans that integrate with TDD orchestration
- Structure tasks for sequential execution
- Clearly define task dependencies and order

### Research Standards
- Conduct comprehensive research before proposing solutions
- Verify all technical information through current sources
- Make evidence-based decisions with trade-off analysis
- Validate solution feasibility through research

### Architecture Design
- Follow Clean Architecture principles
- Design around domain concepts and business rules
- Maintain clear layer separation and dependency inversion
- Consider scalability and maintainability

## Process

1. Research current technologies and best practices
2. Analyze requirements and constraints
3. Design solution architecture
4. Create implementation plan with specific tasks
5. Ensure plan is optimized for TDD orchestration
